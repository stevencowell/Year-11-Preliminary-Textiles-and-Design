Module 1 activity · about 35 minutes

Design-analysis studio

Compare two textile items and build one supported judgement about how well each item responds to its user and purpose.

Your goal

Move from description to analysis

  1. Choose two teacher-approved textile items or clear product images with a similar purpose.
  2. Identify the intended user and end use for each item.
  3. Compare one functional requirement and one aesthetic requirement.
  4. Analyse two elements and one principle using visible evidence.
  5. Make a supported judgement about which item better meets its purpose.
Evidence to save
  • Two item labels or descriptions
  • A functional and aesthetic comparison
  • Two element observations
  • One principle analysis
  • A final supported judgement
