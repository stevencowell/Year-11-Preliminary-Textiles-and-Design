# Year 11 Preliminary Textiles and Design

Student learning website aligned to the NSW Textiles and Design Stage 6 (2013) Preliminary syllabus.

The course contains 15 two-week modules, 45 theory sections, 450 checked questions, 45 saved written responses, 15 PowerPoints, 17 validated video connections, 20 Busy Work activities and a 10-card evidence folio.

Project briefs, practical procedures, WHS controls, assessment schedules and formal task notifications remain controlled by the current teacher-approved school documents.
