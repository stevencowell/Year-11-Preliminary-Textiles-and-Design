Module 1 · Design foundations

From textile idea to design decision

Retrieval: name one textile item you used today. What did it need to do, and what made it visually suitable?

Roadmap

Three connected ideas

  1. Purpose, users and requirements
  2. Elements as visual ingredients
  3. Principles as organising relationships

Theory 1

Begin with user and end use

Functional requirements describe performance. Aesthetic requirements describe the intended visual and sensory effect. Design factors set conditions to recognise and balance.

Think: what might happen if a designer considers appearance but ignores movement, care or durability?

Theory 2

Elements are the ingredients

Line and direction · shape and size · texture · colour and value

Analyse: identify the element, locate the evidence and explain its effect.

Theory 3

Principles organise the elements

Proportion · balance · rhythm · emphasis · contrast and harmony · unity

One textile item can use several principles at once. The analysis must show what is arranged and what effect that arrangement creates.

Learning check

Which statement is analysis?

  1. The garment has red colour.
  2. Red is a colour.
  3. The repeated red panels create rhythm and lead the eye around the hem.
  4. I like the red panels.

Explain what makes one statement stronger than the others.

Written response routine

Read → Select → Explain → Check

  1. Read: identify the command and topic.
  2. Select: choose the most relevant evidence.
  3. Explain: connect evidence to effect or purpose.
  4. Check: answer the actual question and support the judgement.

Exit ticket

One item, one requirement, one element, one principle

Choose a textile item. In four sentences, explain how the designer used one element and one principle to meet one requirement for the intended user.
